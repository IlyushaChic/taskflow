# TaskFlow Frontend

Фронтенд для менеджера задач TaskFlow. Написан на React + TypeScript + Vite + Ant Design.

## 🧱 Технологии

- **React 18** + **TypeScript** – основной фреймворк и типизация.
- **Vite** – быстрая сборка и HMR.
- **Ant Design** – UI-кит (таблицы, модалки, уведомления).
- **Axios** – HTTP-клиент для API.
- **WebSocket** – real‑time обновления (через `gorilla/websocket` на бэкенде).

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск дев-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр сборки
npm run preview
